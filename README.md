## MediPredict

MediPredict is a full-stack AI-assisted disease prediction system that allows users to select symptoms and receive an AI-generated health prediction.

## Features

User registration and authentication

Guest and authenticated predictions

AI-assisted disease prediction

Prediction history for registered users

Detailed prediction results

Responsive medical-focused UI

REST API integration


### Tech Stack

Frontend: React, Vite, Tailwind CSS

Backend: Node.js, Express.js

Database: PostgreSQL

ML Service: Python, FastAPI, Scikit-learn

Authentication: JWT + bcrypt

API Communication: Axios


> Disclaimer: MediPredict provides AI-assisted predictions for informational purposes only and is not a substitute for professional medical advice.
